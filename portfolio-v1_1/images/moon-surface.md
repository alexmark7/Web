# Moon surface imagery

`moon-surface.jpg` is an unmodified 730 × 730 frame from NASA's Scientific Visualization Studio:

- [Moon Phase and Libration, 2026](https://svs.gsfc.nasa.gov/5587/).
- [Original frame 0058](https://svs.gsfc.nasa.gov/vis/a000000/a005500/a005587/frames/730x730_1x1_30p/moon.0058.jpg), 3 January 2026, 09:00 UTC; 99.86% illuminated.
- Credit: NASA's Scientific Visualization Studio. Lunar surface visualization based on Lunar Reconnaissance Orbiter data.
- [NASA media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).

The SVG viewBox crops the black margin to fit the existing circular moon. This local image replaces the procedural noise and hand-drawn crater shapes. It is used only as a static surface texture: the illuminated area still follows the current date through the existing astronomical calculation. No external image request is needed at runtime.
